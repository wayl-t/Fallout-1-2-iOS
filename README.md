# Fallout 1-2 for iOS

Один IPA-лаунчер для Fallout 1 и Fallout 2 на открытых движках fallout1-ce и fallout2-ce.

## Установка

1. Скачайте fallout-launcher.ipa из Releases.
2. Установите через SideStore или AltStore.
3. Запустите приложение и в меню коснитесь верхней половины экрана для Fallout 1 или нижней для Fallout 2.

## Данные игр

Файлы игр в IPA не входят, нужны собственные копии с GOG или Steam.
После первого выбора игры в папке приложения в Files появятся папки Fallout1 и Fallout2.

- Fallout 1: master.dat, critter.dat и папка data - в Fallout1.
- Fallout 2: master.dat, critter.dat, patch000.dat и папка data - в Fallout2.
- Имена файлов должны быть в нижнем регистре.

## Управление

В игре тач работает как трекпад: движение пальца двигает курсор, тап - левый клик, касание двумя пальцами - правый клик.
